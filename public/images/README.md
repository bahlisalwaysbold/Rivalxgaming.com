# Images to add

Every dashed placeholder box on the site tells you exactly what to shoot or
source, right in the component code. Here's the full list in one place —
drop files into this folder with these exact names and the code will pick
them up once you swap the `<PlaceholderImage>` calls for real `<img>` tags.

| File | Used on | What to use |
|---|---|---|
| `hero.jpg` | Home | A dramatic, moody in-game eFootball screenshot or action shot. Wide crop, dark lighting to match the site's black/red theme. |
| `logo.png` | Navbar (optional) | Your Rival X logo on a transparent background (you already have this — the metallic R/X mark). |
| `tournament-t1.jpg`, `tournament-t2.jpg` | Tournaments list | One banner per tournament — an in-game match still, or a mashed-up crest of the two sides if it's a rivalry match. |
| `tournament-t1-banner.jpg` | Tournament detail page | Wider version of the same idea, used at the top of the tournament's own page. |
| `player-avatar.jpg` | Profile page | Square headshot or in-game avatar for the player. Once accounts are live, this becomes an upload each player sets themselves. |

Keep hero/banner images roughly 1600×900 and avatars square (at least
400×400) so they don't stretch.
